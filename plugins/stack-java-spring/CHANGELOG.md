# Journal des modifications du plugin stack-java-spring

Document généré avec l'assistance de l'IA (Claude).

## 0.1.0

* Règles Java et Spring Boot (développement, conception, sécurité, tests, Maven, Gradle, configuration Spring), enrichies des règles de affaan-m/ecc (licence MIT), transmises à Claude à la première lecture ou modification d'un fichier concerné de la session, et seulement dans ce cas.
* Formatage automatique du fichier .java modifié avec google-java-format ou le plugin Spotless du projet, sans installation ni téléchargement.
